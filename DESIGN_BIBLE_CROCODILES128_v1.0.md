# CROCODILES128 --- Design Bible

Revision: 1.0

## Brand Essence

The website is not about aviation. The website is not about software.

It is about engineering.

Aviation exists only as the philosophical inspiration behind every
design decision.

Core values: - Precision - Reliability - Simplicity - Discipline -
Operational Excellence - Continuous Improvement

## Emotional Goals

Visitors should feel: 1. Confidence 2. Professionalism 3. Technical
depth 4. Calm 5. Curiosity

Never: - Loud - Flashy - Gamer aesthetic - AI-generated look - Generic
developer portfolio

## Visual Inspiration

Primary inspiration: - Embraer E190-E2 SharkTech paint language -
Technical manuals - Aerospace engineering drawings - Apple industrial
design - Vercel - Linear - Cloudflare Dashboard

## Color Philosophy

Primary colors: - Pure white - Near black - Neutral grays - Metallic
blue accents

Accent colors should be used sparingly (under 10% of visible UI).

## Typography

Use a clean sans-serif family. Hierarchy must rely on spacing and weight
rather than color.

## Layout

12-column grid. Maximum content width \~1280px. Large whitespace.
Consistent vertical rhythm.

## Motion

Motion should communicate system state. Rules: - 150--300 ms
transitions - Ease-in-out - No bouncing - No exaggerated parallax -
Respect prefers-reduced-motion

## Navigation

Mission Operations Systems Journey Aviation Contact

Language switch: PT \| EN

## Hero

Animated specialties: - Backend Systems - Infrastructure - Networking -

## Iconography

Use simple outline icons. Avoid filled, cartoon or skeuomorphic icons.

## Photography

Professional portrait. Neutral background. Natural expression. No heavy
editing.

## Project Presentation

Each project should include: - Mission - Problem - Architecture -
Stack - Infrastructure - Challenges - Results - Operational Status

Operational statuses: - Production - Closed Beta - Development -
Archived

## Aviation Language

Allowed: Mission Operations Systems Journey Logbook Reliability

Avoid: Cockpit Captain Pilot mode Runway animations Airplane emojis

## Accessibility

WCAG AA minimum. Keyboard navigable. Visible focus. High contrast.

## Performance

Target Lighthouse: Performance \>=95 Accessibility \>=100 SEO \>=95 Best
Practices \>=95

## Tone

Minimal. Technical. Confident. Human.

## Design Rule

Every visual element must answer: "Does this reinforce engineering
excellence?"

If not, remove it.
